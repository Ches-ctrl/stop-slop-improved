# Changelog

## 2026-11-15

### Changed

**SKILL.md** (rewritten around a positive standard)
- Standard: Pinker's classic style and the Plain English Campaign, with a read-aloud test.
- New section 1: settle author, reader, purpose and document type before editing, so pronouns, roles and framing fit the reader.
- New section 2: 15 grammar rules (actor-verb-object, cause before effect, one idea per sentence, keep function words, "will" for forecasts, no hedge on a conditional, state verbs need a value, numerals, one referent per pronoun, headlines up to 2 lines).
- Section 3 merges the old quick checks and adds: bolt-on "with X -ing", trailing and reversed clauses, mid-sentence wedges, balanced pairs with a cause tag, unasked reassurance, vague-third triads, mismatched lists, mixed clauses across a semicolon, idioms for numbers, descriptive Wh- headings, a deck-cliche table, and document-level checks (every visible string, repetition, headline chain).
- New section 4, don't over-correct: passive allowed when the actor doesn't matter; no inventing actors; no compressing past grammar.
- New section 5, process, including an independent reviewer for high-stakes documents.
- New section 6: 10 worked examples and 7 short fixes from a real board proposal.
- Scoring dimensions updated; pass mark raised to 40/50.
