# Structures to Avoid

## Binary Contrasts

These create false drama. State the point directly.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." / "Not because X, but because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliche |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." / "not X, it's Y" / "isn't X, it's Y" | Mechanical contrast |
| "It's not this. It's that." | Same formula, different words |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation-then-assertion crutch |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |
| "It's not X, it just Y" ("it's not cooling, it just feels cool") | Same contrast hidden in one sentence behind a comma |
| "X but Y:" as a label ("Less likely but real:", "Rare but possible:") | Hedge and reassurance in one breath, used to rank list items |
| "X rather than Y" ("annexing rather than drafting", "terminates rather than novates") | The contrast relocated into a subordinate clause, where the not/but check misses it |
| Trailing negative ("I said it to get us closed, not to concede the fee") | Negation-last. Corrects something nobody claimed |

**Instead:** State Y directly. "The problem is Y." "Y matters here." Drop the negation entirely.

"Rather than" earns its place only when the alternative is live and contested. "Added to the loan principal rather than paid in cash" is fair if cash was on the table. "Annexing rather than drafting" is not: say "you'd be annexing."

## Negative Listing

Listing what something is *not* before revealing what it *is*. A rhetorical striptease.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same structure, past tense |

**Instead:** State Z. The reader doesn't need the runway.

## Restatement

Saying the same thing twice at different levels of abstraction, or attaching a label to a point already made.

| Pattern | Problem |
|---------|---------|
| A sentence restating the previous sentence in other words | The reader got it the first time |
| A metaphorical label for the point just made ("that's the load-bearing constraint") | Names the idea instead of adding to it |
| A closing summary of a conclusion already stated | Second helping |
| The same relationship redescribed one level up | Abstraction posing as development |

**Instead:** Keep the version carrying the most information and delete the others. If cutting a clause changes no fact, condition or implication, cut it.

## Concession Pivot

Clearing the innocuous reading first, then revealing the real problem, then stacking a consequence on top.

"Nothing in it contradicts what you agreed - the problem is what isn't in it, and there's an entire agreement clause coming that extinguishes anything not restated."

| Beat | Move |
|------|------|
| "Nothing in it contradicts what you agreed" | Concede the reading the reader might have had, so the reveal lands harder |
| "the problem is what isn't in it" | Pivot to an absence. A binary contrast wearing a dash instead of a full stop |
| "and there's X coming that Y" | Escalation tacked on so the sentence ends heavier than it started |

**Instead:** Lead with the problem. "The draft leaves out things we agreed and the entire agreement clause would wipe out anything the contract doesn't fully restate."

## Dramatic Fragmentation

Sentence fragments for emphasis read as manufactured profundity.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |

**Instead:** Complete sentences. Trust content over presentation.

## Rhetorical Setups

These announce insight rather than deliver it.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |
| "Four ways to deal with it:" then (a) to (d) | Pre-announcing a count the list already shows |
| "I'm not looking to make this the fight." | De-escalation disclaimer. Stacked, it reads defensive |
| "This shouldn't be what stops us moving forward." | Same |

**Instead:** Make the point. Let readers draw conclusions.

## Selling It Back

Ending every item with a line restating what the reader gets.

| Pattern | Problem |
|---------|---------|
| "60x then carries nothing open ended." | Justification tagged onto the proposal |
| "You settle one month rather than four and get a complete release." | Same move, next bullet |
| "which is the protection you're actually asking for" | Tells the reader what they wanted |
| "That closes the point permanently and leaves you nothing outstanding." | Closing reassurance nobody asked for |

One of these is persuasion. Every item carrying one is a machine appending a reason to each bullet.

**Instead:** State the term. The reader can see what it does for them.

## Explanatory Tails

Appending the reason as a relative clause instead of a sentence, or nothing.

| Pattern | Fix |
|---------|-----|
| "..., which is why I'd rather do one of the first three" | New sentence, or cut |
| "..., which is what the contract asks for" | Cut |
| "..., which is the protection you're asking for" | Cut |

## Cleft Constructions

The Wh- crutch moved into the middle of the sentence, where the sentence-starter check misses it.

| Pattern | Fix |
|---------|-----|
| "What I will do is make the commitment to..." | "I'll commit to..." |
| "That's what makes it full and final" | "That makes it full and final" |
| "The test I've used is signature against admin" | "I've split it by signature against admin" |
| "So where this actually sits:" | State where it sits |

## Aphoristic Endings

Closing a paragraph with a fragment declaring that the point mattered.

| Pattern | Problem |
|---------|---------|
| "That distinction matters." | Tells the reader to be impressed |
| "That's the boundary." | Same, with a metaphor |
| "That's the actual constraint." | Same, with "actual" |

**Instead:** End on the last piece of content. If the distinction matters, the reader saw why.

## Formulaic Constructions

| Pattern | Problem |
|---------|---------|
| "By the time X, I was Y." | Narrative template |
| "X that isn't Y" | Indirect. Say "X is broken" |

## False Agency

Giving inanimate things human verbs. Complaints don't "become" fixes. Bets don't "live or die." Decisions don't "emerge." A person does something to make those things happen. AI loves this because it avoids naming the actor.

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | The complaint did nothing. Someone fixed it. |
| "a bet lives or dies in days" | Bets don't have lifespans. Someone kills the project or ships it. |
| "the decision emerges" | Decisions don't emerge. Someone decides. |
| "the culture shifts" | Cultures don't shift on their own. People change behavior. |
| "the conversation moves toward" | Conversations don't move. Someone steers. |
| "the data tells us" | Data sits there. Someone reads it and draws a conclusion. |
| "the market rewards" | Markets don't reward. Buyers pay for things. |

**Instead:** Name the human. "The team fixed it that week" beats "the complaint becomes a fix." If no specific person fits, use "you" to put the reader in the seat.

## Narrator-from-a-Distance

Floating above the scene instead of putting the reader in it.

| Pattern | Problem |
|---------|---------|
| "Nobody designed this." | Disembodied observation |
| "This happens because..." | Lecturer voice |
| "This is why..." | Same |
| "People tend to..." | Armchair sociologist |

**Instead:** Put the reader in the room. "You don't sit down one day and decide to..." beats "Nobody designed this."

## Passive Voice

Every sentence needs a subject doing something. Passive voice hides the actor and drains energy.

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |

**Instead:** Find the actor. Put them at the front of the sentence.

Nominalizations hide the actor the same way. "Merge authority is restricted to the owner role" is "only owners can merge." Turn the noun back into a verb and the actor reappears.

## Borrowed Metaphors

Words standing in for the concrete relationship.

| Word | What it usually means |
|------|----------------------|
| load-bearing | essential, or what everything else depends on |
| gated / X-gated | required, or must happen first |
| surface (verb) | showed, found, reported |
| path | the option or the process |
| layer | the part |
| spine | the main structure |
| drift | change over time |
| landed | finished, shipped, arrived |
| stale | out of date |

Keep the word when it is the clearest description available. Cut it when it stands in for a plain one.

## Sentence Starters to Avoid

| Pattern | Fix |
|---------|-----|
| Sentences starting with What, When, Where, Which, Who, Why, How | Restructure. Lead with the subject or the verb. |
| Paragraphs starting with "So" | Start with content |
| Sentences starting with "Look," | Remove |

Wh- openers become a crutch. "What makes this hard is..." becomes "The constraint is..." or better, name the specific constraint.

## Rhythm Patterns

| Pattern | Fix |
|---------|-----|
| Three-item lists | Use two items or one |
| Questions answered immediately | Let questions breathe or cut them |
| Every paragraph ends punchily | Vary endings |
| Em-dashes | Remove. Use commas or periods. No em dashes at all. |
| Staccato fragmentation | Don't stack short punchy sentences |
| "Not always. Not perfectly." | Hedging disguised as reassurance |
| Balanced epigram ("Repayment follows money, and the obligation follows the entity") | Two parallel short clauses joined by "and". Manufactured gravitas |
| "On [topic]," fronting every paragraph | Fine twice in a structured reply. Eight times it is a metronome |
| The same idea in four costumes ("both ways", "in both directions", "mutual", "bidirectional") | Pick one and use it throughout |

## Word Patterns

| Pattern | Problem |
|---------|---------|
| Lazy extremes (every, always, never, everyone, everybody, nobody) | False authority. Use specifics instead of sweeping claims. |
| All adverbs (-ly words, "really," "just," "literally," "genuinely," "honestly," "simply," "actually") | Empty emphasis. See phrases.md for full list. |

## Over-Correcting

Tightening a sentence introduces its own tells. Check the fix, not only the original.

| Move | Problem |
|------|---------|
| Splitting one point into two sentences | Manufactures a beat the content doesn't have |
| Joining the halves with "then" or "so" | Invents a sequence. Both facts hold at once |
| Cutting a qualifier ("fully restate" to "restate") | Shorter and now inaccurate |
| Present tense on something conditional ("wipes out" for "would wipe out") | Punch at the cost of being wrong |
| Defaulting to "you" | Use the pronoun that matches the real relationship. "we agreed" if you were in the room |

If the shorter version is less true, keep the longer one.
